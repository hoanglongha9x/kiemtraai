# KIEMTRA.AI V3.0 Scaffold

Đây là scaffold ban đầu cho bản xây lại toàn bộ.

## Cài đặt

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Việc cần làm tiếp

1. Tạo Firebase project.
2. Điền `.env.local`.
3. Bật Google Authentication trong Firebase.
4. Tạo Firestore + Storage.
5. Deploy security rules.
6. Build từng module theo checklist trong `docs/BUILD_CHECKLIST.md`.
